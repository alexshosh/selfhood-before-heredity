# Selfhood Before Heredity

**Prebiotic Grounding of a Peptide Coacervate Organization, and Its Route to an Evolvable Quasi-Autogenic Organization**

Alex Shoshitaishvili, Independent Researcher

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22261524.svg)](https://doi.org/10.5281/zenodo.22261524)

## Summary

The paper takes up the origin-of-life "needle-in-a-haystack" problem — how functional
peptide/protein organization could become accessible without an exhaustive search of
sequence space — by reframing it as a percolation problem in peptide/protein
configuration space. It approaches a sought convergence layer, denoted *L\**, from two
independent directions:

- **From the modern-protein side:** GB1-derived interacting peptide fragment systems,
  used as controlled seeds for mapping viable configuration-space connectivity.
- **From the geochemical side:** Deacon's autogenic principle, realized experimentally by
  Matsuo and Kurihara's proliferating peptide coacervate, which is classified here as a
  quasi-autogenic organization (QAG). The paper grounds that laboratory chemistry in a
  physically realizable reaction-space path back to geochemical matter (C/N/S chemistry
  through carbonyl sulfide, natural thiols, and thioester chemistry).
